# AI Resume & Job Match Analyzer

## Overview
This is an AI-powered resume analyzer that compares resumes with job descriptions and provides ATS-based suggestions.

## Features
- Resume Match Percentage
- Missing Skill Detection
- ATS Suggestions
- AI Resume Feedback
- Job Match Analysis

## Technologies Used
- Python
- Streamlit
- Google Gemini API

## Project Goal
This project helps job seekers improve resumes according to company job descriptions using AI.

## Future Improvements
- PDF Upload
- Dashboard Analytics
- Resume Scoring
- Live Job Recommendations
